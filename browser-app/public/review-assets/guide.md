# 知数示范订单体验指南

全部为固定随机种子生成的合成数据，无真实客户。360条记录，每行一笔订单，2026年1—6月每月60条。地域、渠道、品类分布为演示用途，不代表市场事实。

## 统计口径

order_id订单编号；order_date订单日期；order_month预生成月份，避免使用当前不支持的日期函数。region为华东/华南/华北/西部，channel为官网/小程序/门店，category为数码/家居/运动。status为完成/已退款/已取消；quantity为下单件数（含取消）。

gross_amount为下单原价，discount_amount为下单优惠；paid_amount在取消订单为0，否则等于原价减优惠；已退款订单全额退款，refund_amount等于实付，其余为0；net_amount=paid_amount-refund_amount。不包含成本、税费或部分退款，净额不能称为利润。

## 可以查询什么

订单总数；区域、渠道、品类和月份净额；各状态订单数；已退款金额；完成订单平均实付；高金额订单；指定区域/渠道/月份的筛选。要统计有效销售件数需明确status等于完成。月份分析当前以条形图展示，不是已上线折线图。

## 怎么体验

打开/review，切到交互体验。先在产品账户中注册或登录，点击“导入示范数据”；这会通过真实上传和字段确认接口创建本人数据集，并占用一份文件额度。选择示例问题，再选择“自然语言填入”或“SQL填入”，最后在产品中主动点击开始分析。自然语言会调用已配置的DeepSeek并计入模型额度；SQL不调用模型。仅SQL选项不会查询数据。

可下载本CSV自行上传。导入字段类型：order_date选日期、quantity选整数、五个金额字段选金额，其余选文本；评审页一键导入会自动应用这些固定类型。

图表适合两列的分类汇总，单值、三列明细等会显示不适配并提供查看表格。试试“海外”区域查看空结果；试试“利润是多少”验证缺字段澄清；输入DROP TABLE data验证安全拒绝（不应产生删除）。不支持LIKE、跨表、窗口、预测与因果分析。

## 核验与清理

示例SQL的确定性真值见expected-results.json；它用于复核而不是冒充实时答案。交互界面不把这些预计算值当查询结果。体验后可在产品数据管理中删除示范文件。重复导入会新建一份文件；页面会在本次打开期间提示已导入，刷新后需重新选择或导入。
